# X ID

Turn any public X profile into a tilt-reactive holographic identity card.

**Try it:** <https://dcgancan.github.io/xid/>

Type a handle, choose a finish, then drag the card on desktop or tilt your phone.
Share the result straight to X.

Inspired by [@avstorm's holographic verification card](https://x.com/avstorm/status/2084560773779493228).

## Run locally

```sh
bun install
bun run dev
```

Public profile data only. Nothing is stored.
